# distillation-collapse
Experimental methodology to combine dataset distillation methods with the principles of Neural Collapse as outlined by Zhu et al. in A Geometric Analysis of Neural Collapse with Unconstrained Features (https://doi.org/10.48550/arXiv.2105.02375) and Kothapali in Neural Collapse: A Review on Modelling Principles and Generalization (https://doi.org/10.48550/arXiv.2206.04041). Based off [Exploiting Inter-sample and Inter-feature Relations in Dataset Distillation by Deng et al](https://arxiv.org/pdf/2404.00563). 


# Abstract
Dataset distillation is a method in deep learning that allows for more efficient training of neural networks by generating smaller synthetic datasets based off the original dataset. This enables faster network training using less computing time, but current methods of dataset distillation consistently result in lower overall accuracy compared to training with the entire dataset. To this end, we leverage an unusual phenomenon in deep learning known as neural collapse, where the last-layer representations of training samples with identical labels collapse into the class mean. This suggests that selecting for specific outliers in the feature representation may be useful for increasing accuracy in dataset distillation. To this end, we introduce a novel constraint to the standard process of dataset distillation using the demonstrated principles of neural collapse. This constraint matches the between-class variability collapse of the synthetic dataset to that of the original dataset, which encourages better class discrimination and similar features between the synthetic and original dataset. So far, there appears to be no effect or a detrimental effect on the final trained accuracy with this constraint, but we are actively fine-tuning the details of this constraint.
